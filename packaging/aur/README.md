# AUR packages (I2PChat-ng)

Install with an AUR helper (x86_64 and aarch64):

```bash
yay -S i2pchat-bin         # GUI (release AppImage)
yay -S i2pchat-tui-bin     # TUI (release zip)
yay -S i2pchat-ng-git      # GUI from git
yay -S i2pchat-ng-tui-git  # TUI from git
```

| Package | What you get |
|---|---|
| [i2pchat-bin](https://aur.archlinux.org/packages/i2pchat-bin) | Official GUI AppImage → command `i2pchat` |
| [i2pchat-tui-bin](https://aur.archlinux.org/packages/i2pchat-tui-bin) | Official TUI zip → command `i2pchat-tui` |
| [i2pchat-ng-git](https://aur.archlinux.org/packages/i2pchat-ng-git) | Build Qt 6 GUI from this repository |
| [i2pchat-ng-tui-git](https://aur.archlinux.org/packages/i2pchat-ng-tui-git) | Build FTXUI TUI from this repository |

**Not this project:** [i2pchat-git](https://aur.archlinux.org/packages/i2pchat-git) is a different client ([vituperative/i2pchat](https://github.com/vituperative/i2pchat), Qt5).
